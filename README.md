## توضیحات پروژه 📌
<!-- Project Description : استاندارد  -->

## ویژگی ها  
<!-- Features : استاندارد -->
- دریافت داده‌های زنده از یک API خارجی (Dad Jokes API) با استفاده از Fetch و Promises
- ارسال هدرهای سفارشی (`Accept: application/json`) برای دریافت پاسخ با فرمت ساختاریافته
- طراحی کارت واکنش‌گرا و مدرن با انیمیشن‌های CSS Transition و Scale
- استفاده از واحدهای مدرن Viewport (`100dvh`) برای کنترل ارتفاع صفحه
- کدنویسی سبک، تمیز و کاملاً بدون وابستگی به فریم‌ورک‌های سنگین

## Project Description 📌
<!-- Standard : Project Description  -->
This project is an interactive web application that fetches random Dad Jokes from an external API using the Fetch API. Users can click a button to instantly fetch and display a new joke for a fun “Don’t Laugh Challenge”.




---
---
---

## Features 🌏
<!-- Standard : features  -->
- Live data fetching from an external API using Fetch and Promises
- Custom request headers (Accept: application/json) for structured JSON responses
- Modern, responsive card layout with CSS transition and scale effects
- Utilization of modern Viewport units (100dvh) for precise height scaling
- Lightweight, clean, and dependency-free codebase
